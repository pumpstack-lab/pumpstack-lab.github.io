Sarto 利用規約

制定日：2026年11月13日

第1条（定義）

本規約において、次の用語は、それぞれ次の意味で使用します。

  • 「当方」：PumpStack Lab.
  • 「本サービス」：当方が提供する、サロン向けの予約ページおよび店舗用管理画面「Sarto」
  • 「契約者」：本規約に同意のうえ、本サービスの利用を申し込んだ事業者
  • 「申込みフォーム」：当方が指定する、本サービスの申込み用のページ
  • 「利用開始日」：当方が予約ページを公開し、その旨をメールで契約者に通知した日
  • 「本契約」：第2条により成立する、本サービスの利用契約

第2条（契約の成立）

  1. 本契約は、契約者が申込みフォームにおいて本規約に同意のうえ送信し、当方が契約者に対しメールで請求書を送付した時に成立します。
  2. インスタグラムのダイレクトメッセージ、LINE その他のメッセージのやりとりのみでは、本契約は成立しません。
  3. 本サービスは、契約者が自らの事業のために利用するものとします。

第3条（サービスの内容）

初期費用に含まれるもの

  1. 契約者専用の予約ページおよびその URL の提供
  2. スタッフ、ベッド（席）、営業時間および定休日の初期設定
  3. 現在のメニューの登録（30件まで）
  4. 利用方法の案内（説明ページおよびメール等による案内）

月額利用料に含まれるもの

  1. 予約ページおよび店舗用管理画面の利用
  2. 軽微な設定変更の代行（月2回まで）。なお、メニュー、営業時間、スタッフ等は、契約者が管理画面から回数の制限なく変更できます。
  3. メールによる問い合わせへの対応（回答の目安：3営業日以内）

含まれないもの（別途ご相談・お見積り）

  • 新しい機能の開発、契約者独自のデザインへの変更
  • 他の予約サービスからの顧客情報の移行
  • 訪問による説明、24時間の緊急対応
  • LINE による自動通知およびクレジットカードによる事前決済。これらは準備中であり、提供の時期および料金は未定です。本契約には含まれません。

第4条（利用料金および支払方法）

項目金額（お支払いの総額）支払時期
初期費用33,000円初回の請求書の支払期限までに1回
月額利用料6,600円毎月末日までに翌月分を前払い
  1. 初回のお支払いは、初期費用および最初の有料月（利用開始日の属する月の翌月）分の月額利用料の合計 39,600円とします。契約者は、請求書の送付日から7日以内に、銀行振込によりお支払いください。期限までにお支払いが確認できない場合、当方は、本契約を解除できます。
  2. 利用開始日からその月の末日までの月額利用料は、無料とします。
  3. 当方は、初回のお支払いを確認した後、メールで制作開始を通知したうえで、制作に着手します。
  4. 最初の有料月の翌月分以降の月額利用料は、毎月末日までに翌月分をお支払いください。支払方法は、銀行振込または当方が案内するクレジットカードの自動決済とします。
  5. 振込手数料は、契約者の負担とします。
  6. 当方は、適格請求書（インボイス）発行事業者ではありません。
  7. 当方が利用料金を改定する場合は、1か月前までにメールで通知します。

第5条（契約期間）

  1. 契約期間は、本契約の成立日から、利用開始日の属する月の翌月末日までとします。契約者から次条の解約の通知がない限り、同一の条件で1暦月ごとに自動的に更新されます。
  2. 最低利用期間および違約金の定めはありません。

第6条（解約）

  1. 契約者は、解約を希望する月の前月末日までに、メールで当方に通知することにより、本契約を解約できます。期限は、契約者が通知を送信した日を基準とします。
  2. インスタグラムのダイレクトメッセージまたは LINE による通知も、当方の代表者あてのものに限り、有効とします。この場合、当方は、メールで確認の連絡を行います。
  3. 第1項の期限までに通知が送信されなかった場合は、解約は翌月の末日をもって効力を生じ、翌月分の月額利用料が発生します。
  4. 契約者は、解約月の末日まで本サービスを利用できます。当方は、その翌日に予約ページを停止します。
  5. 当方は、解約後30日間、予約および顧客のデータを保管し、その後に削除します。契約者から希望があった場合は、顧客リストを CSV 形式のファイルにより、メールで提供します。

第7条（返金）

  1. 契約者からの返金の申し出が、当方による制作開始の通知より前に当方に到達した場合は、初回のお支払いの全額を返金します。返金に係る振込手数料は、契約者の負担とします。
  2. 当方が制作開始を通知した後は、初期費用は返金しません。
  3. 第1項の場合を除き、お支払い済みの月額利用料は、返金しません。

第8条（サービスの停止および変更）

  1. 月額利用料のお支払いが期限までに確認できない場合、当方は、メールでその旨を通知します。支払期限の翌月10日までにお支払いが確認できない場合、当方は、予約ページを停止します。お支払いが確認できた場合は、2営業日以内を目安に再開します。停止期間中の月額利用料も発生します。
  2. 予約ページの停止から30日を経過してもお支払いが確認できない場合、当方は、本契約を解除できます。
  3. 緊急の保守、天災その他の不可抗力、または当方が利用する外部サービス（サーバー等）の障害が生じた場合、当方は、事前の通知なく本サービスを一時的に停止することがあります。
  4. 当方は、改善を目的として、本サービスの機能および画面を変更することがあります。重要な変更については、1か月前までに通知します。

第9条（禁止事項）

契約者は、次の行為をしてはなりません。

  1. 本サービスを第三者に貸与し、または譲渡すること
  2. 本サービスを法令に違反する目的で利用すること
  3. 当方のシステムへの不正なアクセス、または本サービスの解析もしくは複製を行うこと

第10条（責任の制限）

  1. 当方は、本サービスの利用または利用できなかったことにより契約者に生じた損害（逸失利益を含みます）について、当方に故意または重大な過失がある場合を除き、責任を負いません。
  2. 前項の場合を除き、当方が責任を負うときであっても、その賠償額は、損害が生じた月の月額利用料の額を上限とします。
  3. 当方は、当方が利用する外部サービスの障害により生じた損害について、責任を負いません。

第11条（顧客情報の取扱い）

  1. 本サービスを通じて取得された顧客の情報（氏名、連絡先、予約の記録等）は、契約者に帰属します。
  2. 当方は、本サービスの提供に必要な範囲でのみ当該情報を取り扱い、第三者に提供しません。当該情報は、当方が利用する外部サービス（サーバー等）に保管します。
  3. 契約者は、顧客情報の取得および利用目的について、自らの責任において顧客に説明するものとします。
  4. 当方は、個人情報の保護に関する法律を遵守し、当該情報を適切に管理します。

第12条（秘密保持）

当方および契約者は、本契約に関連して知り得た相手方の業務上の情報を、第三者に開示しません。ただし、法令に基づき開示を求められた場合は、この限りではありません。

第13条（規約の変更）

当方は、本規約を変更することがあります。変更する場合は、その内容を1か月前までにメールで通知します。

第14条（準拠法および管轄）

本規約は、日本法に準拠します。本サービスに関して紛争が生じた場合は、当方の所在地を管轄する地方裁判所を、第一審の専属的合意管轄裁判所とします。
