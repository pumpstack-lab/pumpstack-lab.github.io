# 設計書：TableStack命名・店舗配布1枚紙・PSL LPライト改修（2026-07-04）

> 関連: 2026-06-04-psl-lp-redesign（フルリデザイン案件）— 今回はその上へのコンテンツ4項目ライト追加＋1枚紙同梱で、フルリデザインは対象外。

## 目的

外部営業の初回接触を強くする。①外販予約サービスに正式名称を付け、②店舗手渡し用のA4両面1枚紙を作り、③LPをライト改修して1枚紙をDL資料として同梱する。1回のpushで完結。

## 確定事項（オーナー承認済み）

1. **サービス名：TableStack（テーブルスタック）**
   - 表記：`TableStack（テーブルスタック）by PumpStack Lab.`（初出のみフル・以降TableStack）
   - 位置づけ：PSL製品ファミリー「Stackシリーズ」（CareStackと兄弟・将来サロン版等も同型命名可）
   - 既存システムの内部呼称は外販商品名には使わない。実績表記は従来通り「福岡県内某飲食店で本番稼働中」（店名実名は出さない・プライバシー配慮ルール踏襲）
   - 条件（ネイト）：本格展開前にJ-PlatPatで商標簡易確認を1回（別タスク・push前提条件にはしない）
2. **1枚紙は飲食寄せの汎用版1種**（業種別分割は反応を見てから）
3. **料金掲載は予約受付（TableStack）のみ具体額**：初期¥30,000＋月額¥6,000〜（税抜）。他ツールはヒアリング後に無料見積（LP表示方針の正本に整合）
4. **構成の型は才流A4ペライチ**（表面＝キャッチ→課題→解決後の姿／裏面＝実績・料金・FAQ・CTA）。デザインはテンプレ流用せずPSLブランドで自作
5. **文言原則（debono）：機能ではなく状態変化で書く**（例:「予約システム導入」→「予約の電話が鳴らなくなる」）

## 成果物① 店舗配布1枚紙（A4両面・PDF）

- 実装：HTML 2ページ（A4印刷CSS `@page` / 210×297mm）→ PDF化。ソースHTMLもリポジトリに残す（次回改訂用）
- 配置：`assets/tablestack-onepager.pdf`（＋ソース `assets/tablestack-onepager.html`）
- デザイン：PSLブランド踏襲（青 #2563eb／紫 #7c3aed・Noto Sans JP・logo.png）。印刷前提のため白背景基調・文字グレーは印刷で薄くなりすぎない濃度にする
- **表面**：
  - ヘッダー：PSLロゴ＋「TableStack（テーブルスタック）」＋一言（誰向け・何が変わるか）
  - キャッチ：状態変化型・15〜25文字（例:「予約の電話、鳴らなくなります。」）
  - 課題3点（営業中の電話対応・ダブルブッキング・大手サイトの手数料）
  - 解決後の姿3点（Web予約24時間受付・LINEに自動通知・自動の重複チェック等、実機能ベース）
  - 実績1行（福岡県内某飲食店で本番稼働中）
- **裏面**：
  - 主要機能（LINE自動通知・席自動確保・変更/キャンセル・顧客リスト等、LP掲載済みの実機能のみ）
  - 料金：TableStack 初期¥30,000＋月額¥6,000〜（税抜）／手数料なし／相談・見積無料
  - FAQ 3問（料金・縛りや強引な営業なし・導入後サポート）
  - CTA：LINE友だち追加QR（右下・ラクスル定番配置）＋メールアドレス
- QRコード：`segno`（純Python・依存なし）で `https://line.me/R/ti/p/@425ukgwa` から生成。作業用ツールとしての単発利用でプロジェクト依存には追加しない
- **誇張禁止チェック**：数字・実績はすべて実態ベース（導入件数・継続率などの未実績数字は書かない）

## やらないこと（YAGNI）

## 検証・完了条件

静的サイトのためpytestなし。以下で代替：
1. ローカル `python3 -m http.server` でPC幅＋スマホ幅（375px）目視・リンク/PDF DL動作確認
2. 1枚紙PDFを実寸プレビューで確認（文字切れ・QR読み取りをスマホ実機で）
3. **オーナー目視OKをもらう**（LP＋1枚紙PDF両方）
4. push前チェックリスト完走（verification-before-completion／ネイト精査＝誇張チェック含む／impeccable critique／code-review／finishing-a-development-branch）→ push
5. 個人情報・認証・DB変更なし → security-reviewは対象外（静的コンテンツのみ）
